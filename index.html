設定 — API キー

    
    
キーは console.typesafe.ai/keys で発行できます。このブラウザの localStorage にだけ保存され、API 呼び出しのたびに Authorization ヘッダとしてこのデモのプロキシ経由で TypeSafe に送られます。プロキシはキーを保存・記録しません。
